# 공개 자료 기반 계정 분석

확인일: 2026-10-06. 공개 브라우저에서 직접 확인. 인스타 개별 게시물은 로그인 요청으로 본문 분석 불가. 공개 썸네일·소개 및 네이버 프롤로그에 한정.

## 확인한 사실
- https://www.instagram.com/ldhpd_80/ : 이동현. 소개는 영화감독·영상제작 PD, AI Film·Documentary, 문의 DM. studioednc.com 링크. 관찰 시 팔로워 224명. 썸네일에는 현장 장비와 인물 사진이 보임. 공개 접근에서 제공된 목록이 최신 전체 목록인지는 확인 불가.
- https://blog.naver.com/gage_otd : 스튜디오이디앤씨 / 곰돌이피디. 2026-09-28 소상공인 인터뷰 홍보영상 안내 글과 다수의 2022년 영화·드라마·영상 제작 글 노출.
- 기존 목록에 색보정 강의 정리, 아이폰 영화 색감, 소니 Log 후반작업, 영상 구도와 편집 팁이 있음. 본문 전체는 이 분석에서 읽지 않음.
- 저장소 index.html에는 검정 #0a0906, 크림 #efe9dd, 노랑 #ffcd4a 및 녹색 계열 브랜드 토큰 사용.

## 콘텐츠 방향 제안 (성과 분석 결과가 아닌 가설)
기존 감독·PD 정체성과 연결해 '곰돌이피디의 색보정 첫걸음' 시리즈로 구성. 본인 촬영 영상과 Resolve 화면을 사용해 실전 신뢰를 보여주기.
릴스: 0–3초 결과/문제 제시 → 실수 하나 → 조작 하나 → 전체 화면 A/B → 연습 안내. 카드뉴스: 문제 → 관찰 → 조작 → 비교 기준 → 저장 안내.
블로그: 같은 주제를 인사·설명·화면 예시·따라하기·주의점으로 확장. 현재 생성기는 짧은 초안만 생성하며 긴 해설과 실제 예시는 편집 필요.

## 권장 주제 순서
1. 노출: 얼굴과 하늘의 밝기는 다르다
2. 화이트밸런스: 피부가 이상하면 채도부터 빼지 않는다
3. 대비: 검은 옷·흰 옷 디테일 확인
4. 채도: 배경이 얼굴보다 튀는지 확인
5. LUT: 입력·출력 색공간 맞추기
6. 컷 매칭: 두 컷의 밝기부터 비교

## 후속 검증
실제 인사이트의 도달, 평균 시청시간, 저장, 공유가 있어야 주제 성과를 판단할 수 있음. 팔로워 수나 썸네일만으로 성과 단정 금지. 공개되지 않은 수치는 수집하지 않았음.

## 게시 자동화
Meta 공식 Instagram Login API로 연결할 후보. 계정의 프로 계정 여부·앱 권한·토큰이 아직 확인되지 않음.
네이버 공식 API 목록에는 블로그 게시용 API가 확인되지 않음. 블로그 검색 API를 게시에 사용하지 않음. 현재는 글·이미지를 묶어 제공하는 방식. 로그인된 편집기 입력 또는 예약 발행 연결은 별도 구현·검증 필요.
